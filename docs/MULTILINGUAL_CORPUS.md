# Multilingual Corpus

The ProX-AI corpus is moving towards a structured multilingual distribution.

## Phase 2 Targets
- **Total Tokens**: 1B
- **English/General**: 350M
- **Programming Languages**: 250M
- **Technical Documentation**: 150M
- **Hindi**: 150M
- **Mathematics/Reasoning**: 75M
- **Other Indic Languages**: 25M

## Programming Language Breakdown
Programming data is balanced across Python, C, C++, JS, TS, Rust, Go, Java, SQL, C#, Kotlin, Swift, Shell, HTML/CSS, and ProXPL.
