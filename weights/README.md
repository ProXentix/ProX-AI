# Weights Directory

This directory contains trained model checkpoints and saved tokenizer artifacts.

Subdirectories:
- `weights/neurix/`: Neurix model checkpoints (`checkpoint-step-XXXX.pt`).
- `weights/tokenizer/`: Trained ProX BPE Tokenizer artifacts (`vocab.json`, `merges.txt`, `tokenizer_config.json`).
- `weights/logix/`: Logix specialized checkpoints.
- `weights/optix/`: Optix vision-language checkpoints.
